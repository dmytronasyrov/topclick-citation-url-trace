    Capture and inspection are different observations
    Save the answer occurrence with its engine, query reference and capture time. The displayed label helps a reviewer locate it, but the original href identifies the link itself. A screenshot can preserve appearance while still leaving the target URL unknown.
    Record route inspection at its own time. If a link now redirects to a different host, retain both the original href and the recorded destination. The worksheet does not infer historical routing from a later trace, or treat a matching hostname as proof that the source supports the answer.
    Keep the response sequence explicit
    For this worksheet, supported redirect statuses are 301, 302, 303, 307 and 308. The next address is calculated from the entered Location and the current response URL. Relative paths are supported. A redirect without Location leaves a gap; a repeated address exposes a possible loop in the supplied sequence.
    A final 2xx response closes the entered HTTP route. Other statuses, including access failures, leave the destination unresolved here. This is a proposed reporting convention for this tool, not a universal citation acceptance standard.
    Retain raw values when comparing addresses
    The JSON export preserves the original input strings. Comparisons use parsed HTTP(S) addresses and ignore fragments, which are not part of an HTTP request target. Query parameters remain part of the comparison; their order and values are not silently rewritten.
    Only HTTP(S) URLs without embedded credentials are accepted. CSV export quotes fields and prefixes spreadsheet formula-like values with an apostrophe. Use JSON when byte-for-byte input text preservation matters. Neither format is a signed or tamper-evident audit trail.
    A canonical note cannot complete a route
    A canonical declaration expresses a preferred URL for duplicate or similar content. It is a separate observation from an HTTP response chain. Google treats canonicalization methods as signals; the worksheet makes no claim about Google's selected canonical URL.
    The optional canonical note is exported without affecting route classification. The different-final-URL example deliberately includes a canonical note matching its declared final URL. That note does not repair the conflicting terminal response.
