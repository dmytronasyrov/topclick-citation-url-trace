# TopClick citation URL trace

Static local worksheet for manually entered citation evidence. No URL fetcher, AI querying, analytics or storage. It tests input continuity only, not truth, source support or report acceptance.

Publish `docs/` with GitHub Pages. Run focused tests with `node --test test/model.test.mjs` (Node with built-in test support). Open through an HTTP server for ES modules.

Rule version: 2026-11-14.1. Five fictional cases use reserved `.example` addresses. JSON preserves original input text; CSV adds spreadsheet formula protection. Source, dates, scope and affiliations are visible in the page.

The public repository contains only authored site code, fixtures, model tests and this README. Private editorial research and publication records stay outside the deployment repository.
